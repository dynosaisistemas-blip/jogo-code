# videos/

Coloque aqui os vídeos enviados para edição. As saídas de cada sessão de
edição ficam em `videos/edit/` (transcrições, EDL, animações, preview e
`final.mp4`).

Nada nesta pasta é versionado no git (arquivos grandes). Baixe o `final.mp4`
quando o agente enviar o resultado na conversa.

Pipeline: ver `.claude/skills/editar-video/SKILL.md`.
